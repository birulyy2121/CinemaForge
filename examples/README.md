# CinemaForge Example Compositions

This directory contains complete, standalone motion graphics compositions built with **HyperFrames** and **GSAP**, ready to render to 4K 60fps MP4 with 4× subframe motion blur.

## Included Examples

- **`product-launch.html`** — Complete 30-second SaaS product launch ad featuring the 4-act dramatic structure, spring-overshoot browser mockups, real-time counters, and staggered feature callouts.
- **`kinetic-type.html`** — 20-second kinetic typography manifesto video featuring word punches, character cascades, scale explosions, and beat-synced rhythm.
- **`dashboard-reveal.html`** — Executive KPI dashboard showcase featuring rolling odometer counters, bar chart growth with spring physics, and animated SVG uptime dials.
- **`social-reel.html`** — 9:16 vertical social video (Instagram Reels / TikTok / YouTube Shorts) with 0.3s snappy transitions, phone mockup framing, and seamless loop design.
